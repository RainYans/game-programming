## Done — farm scene & avatar

- **Avatar:** WASD movement via Rigidbody2D (collides with solids); `AvatarController` +
  `AvatarInteraction`. Cinemachine `FollowCamera` (Framing Transposer + `CinemachineConfiner2D`),
  scroll-zoom via `CameraController`. (Do NOT scale the FarmGrid transform — it desyncs
  `WorldToCell`.)
- **Interaction:** walk up + **E** is context-sensitive — open the nearest building, else
  plant/harvest the cell underfoot.
- **Map:** isometric `GroundTilemap` (~20×20 ground, centered plantable field). Real iso tile
  art (Kenney + a 256px sheet) wired via the tile setup menus.
- **Buildings (placeholders):** Home (manual save), Shop (real panel), Lab (toast), WarCamp
  (opens the deploy/battle page).
- **Scenery:** wall ring, mountains, invisible `MapBoundary`, painted river.

## Done — Milestone 1 (zombie foundation)

- **Six strains:** `ZombieData` carries HP / Attack / MoveSpeed / melee-or-ranged + a single
  `Passive` flag enum. Three starting strains plantable (Brute / Mauler / Runner); all six
  (+ Spitter / Shaman / Bomber) generated by **Tools > Zombie Farm > Setup Zombie Strains**
  into `Assets/ScriptableObject/Strains/`.
- **Per-unit roster:** `Inventory` now holds individual `ZombieUnit`s (uid + strainId + a
  "became full" timestamp), not just counts — still exposes the old count API so the roamer
  spawner / counter UI / deploy screen are unchanged.
- **Hunger:** Full ↔ Hungry state machine, derived from wall-clock time vs
  `GameConfig.hungerDelaySeconds` (like crop growth, so it's correct across saves). Persisted.
- **Seed-pick popup:** planting on empty soil opens a hand-built dialog under the Canvas
  (`SeedPickPopup`); rows clone a template per `GameConfig.seedCatalog` entry, showing owned
  counts. Built by **Tools > Zombie Farm > Setup Seed Pick Popup**.
- **Roamers are per-unit:** `FarmRoamerSpawner` reconciles one roamer per `ZombieUnit` (keyed
  by uid); each `FarmRoamer` shows a floating label = strain name, colored by hunger
  (white = Full, orange "!" = Hungry), polled over time.
- **Save/load:** zombie units persisted; legacy count-only saves migrated to units on load.
- **Editor menus added:** Setup Zombie Strains, Setup Seed Pick Popup, Save File >
  Delete / Open.
